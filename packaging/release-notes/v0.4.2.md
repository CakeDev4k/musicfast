- **Músicas carregando para sempre:** se a instalação do yt-dlp falhar (rede caiu, GitHub bloqueado, antivírus), o app tenta de novo em um minuto e avisa, em vez de ficar girando até ser reaberto. Uma playlist cuja fila não veio também para de carregar e mostra o erro.
- **Antivírus e proxy:** funciona com antivírus que inspecionam HTTPS (Kaspersky, Avast, ESET) e com o proxy configurado no sistema. Se o antivírus apagar o yt-dlp, ele é reinstalado sozinho; se bloquear, o aviso diz isso.
- **Erros mais claros:** quando o problema não é da música (sem conexão, o YouTube pedindo para confirmar que não é um robô, limite de pedidos), o app para na hora com o aviso em vez de tentar mais três músicas.
